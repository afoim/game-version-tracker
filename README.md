# Game Version Tracker

采集原神、星穹铁道、崩坏3、绝区零、鸣潮、终末地、异环、蔚蓝档案日服和星塔旅人国服，输出 `data/games.json`，保持现有前端字段兼容。

```powershell
python src/main.py
```

Python 3.13，仅使用标准库。回归测试：`python -m unittest discover -s tests -v`。

日常维护由 ChatGPT 定时任务驱动：AI 会通过 AgentDock 在本机拉取仓库、运行测试与采集器，并独立核对官方公开来源；发现过期硬编码、公告格式变化或解析失败时会修复代码、回归测试、重新生成数据并在验证通过后提交推送。详细流程见 `AI_RUNBOOK.md`。GitHub Actions 保留为手动 deterministic fallback，不再承担每日 cron，避免与 AI 调度并发冲突。

鸣潮将明确的上线文案与前瞻公告分开解析；预告中的更高版本不会成为当前版本。有完整年份和时间的上线公告按实际时间切换；3.6 的历史维护结束时间保留为仅绑定该版本的种子。新版本缺少可核实的日期时明确失败，绝不沿用旧版本日期或把前瞻日期当作上线日期。来源被限流、暂时不可达或返回 WAF 挑战时，鸣潮请求最多尝试三次。

采集器报错后仍检查其余游戏并打印逐项结果；任意一项失败则整批返回失败并保留上一份数据，避免发布缺失游戏或静默伪装成最新数据。输出通过临时文件原子替换，不删除其他数据文件。

已知边界：部分游戏的版本日期、内容和卡池仍使用历史手工值；42 天等周期是估算，不能当作官方确认时间。接口调用成功不证明这些手工字段仍有效。鸣潮目前解析列表可见的完整公告，缺失日期或公告格式变化会显式报错，仍需维护适配器；每天调度不能替代来源更新和解析维护。
